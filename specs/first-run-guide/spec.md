# 首次启动引导流（3 步可跳过）

## 背景

App 装上后的第一次打开，用户看到的是**选音源页**（`SourceSelect`）—— 选完就进剧场，
**再没有任何说明**：

- 这个 App 到底能干什么（聚合四个音源 / 统一搜索 / ❤ 库 / AI 推荐 / 歌词）
- AI 推荐要 DeepSeek key，没有 key 就用不了，但没人告诉他
- 快捷键（`⌘⇧L` lite / `⌘⇧M` mini / `⌨` 速查面板）**存在但没人知道**
  —— #134 刚把速查面板做出来，正是「该让人看见」的时机

功能盘点里「首次启动引导」是 P2（`onboarding / 首次引导 → 0 处`，前后端都没有
⇒ 纯新增）。

## 范围

**做**：选完音源后的**一次性** 3 步引导（欢迎 → AI 推荐（可选）→ 上手），
每步都能跳过，跳过/完成后不再打扰；设置里能重看。

**不做**：多语言、教程视频、新手任务/成就系统、引导里做账号登录
（登录仍走各平台自己的登录流程）、引导里的音源选择（那步已经有了）。

## 三步

| 步  | 标题    | 内容                                                           | 出口                      |
| --- | ------- | -------------------------------------------------------------- | ------------------------- |
| 1   | 欢迎    | 三件事：四个音源聚合 / 统一搜索 + ❤ 库 / AI 推荐 + 歌词        | 「开始」                  |
| 2   | AI 推荐 | DeepSeek key 的用途；「现在设置」打开**已有的** `RecoKeyModal` | 「现在设置」/「以后再说」 |
| 3   | 上手    | 搜索在标题栏 / `⌘⇧L` lite / `⌘⇧M` mini / `⌨` 速查面板          | 「开始使用」              |

## 决策

- **只在选完音源后出现**：选音源那步**已经有了**（`!player.provider` →
  `SourceSelect` 全屏页），不重复造；引导接在它**后面**。
- **flag 存 localStorage**（`maestro:onboarding-done`）：这是**本机使用痕迹**
  （跟搜索历史同款），不是用户资产 ⇒ 不进服务端的 session 分片、不进 ❤ 库。
- **任何一步都能跳过**：右上角「跳过」+ 第 2 步的「以后再说」⇒ 写 flag ⇒
  **不再打扰**（用户自己选的路，不该反复拦）。
- **设置里能重看**：跳过了也能再打开（设置 → 「重新看引导」）—— 引导是**帮助**，
  不是**关卡**。
- **第 2 步复用 `RecoKeyModal`**：不重写 key 输入（两处输入框 = 两份校验规则
  = 迟早不一致）。
- **不引新依赖**：纯 React + 现有样式变量。

## 验收标准

- [ ] 首次启动（选完音源 + 没看过引导）→ 引导出现
- [ ] 三步都能走完；**任何一步都能跳过**
- [ ] 跳过 / 完成后重启 App → **不再出现**
- [ ] 设置里能「重新看引导」
- [ ] 选音源那步**不受影响**（引导不挡在它前面）
- [ ] 全量套件 `EXIT=0` + 覆盖率 diff 门禁绿 + 变异验证（flag 写失败 → 引导会
      反复出现 ⇒ 必须被测出来）
- [ ] 引导是**全屏覆盖层**：挡住标题栏 ⇒ 用户不能「看不见它」但继续用

## 局限（如实记录）

- 只在**选完音源后**出现；用户如果停在选音源页，引导不会出现（那是另一个页面）
- 引导内容是**静态文案**，不随平台/登录态变化
- 跳过后靠 flag 记忆 ⇒ 清 localStorage 会重新看到引导（可接受：不是 bug）

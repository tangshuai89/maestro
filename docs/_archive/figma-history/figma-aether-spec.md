# AETHER ENGINE — Maestro 音乐播放器 Figma 设计规格

目标：在 Figma 文件 `FtbRZXvzlCp4Sq9e322cQQ`（Maestro AETHER Music Player）中构建完整的
跨平台音乐播放器界面，AETHER 酸性赛博/宇宙能量风格（用户选定方向）。

## 画布与整体

- 主 Frame：`AETHER — Canvas`，1440×900，深空黑渐变背景（#0A0518 → #02020A 垂直渐变）
- 全屏氛围层：星尘粒子（白色半透明小圆点，随机分布）、透视网格（底部地平线网格线、
  rgba(255,255,255,0.03)）、星云光晕（左上电紫 #5B2BFF 模糊光斑、右下霓虹青 #00E5FF 模糊光斑）
- 所有面板：半透明玻璃（白 5-8% 填充 + 1px 白 10% 描边 + 24px 圆角），backdrop 效果在
  Figma 中用 fill 透明度 + 描边模拟

## 设计 Token

| Token | 值 | 用途 |
|---|---|---|
| bg-top | #0A0518 | 背景顶部 |
| bg-bottom | #02020A | 背景底部 |
| neon-cyan | #00E5FF | 主强调：播放键/进度/激活态 |
| electric-purple | #5B2BFF | 星云/光晕 |
| acid-purple | #B57BFF | AI 元素/高亮标签 |
| off-white | #F5F0E8 | 主文字 |
| heart-red | #FF3B5C | 红心/收藏 |
| neon-green | #3DFFA2 | 同步完成 |

字体：Inter（标题用 Bold/Black + 大号字距；数据用 JetBrains Mono 风格等宽——Figma 若无
JetBrains Mono 用 Menlo/Monaco 代替）、正文 General Sans 回退 Inter。

## 布局结构（自上而下，全部保留现有功能）

### 1. 顶部状态条（40px 高，全宽）
- 左：雷达/状态指示（同心圆环 + 扫掠 + 中心点，青色描边）+ `AETHER_SYSTEM_ACTIVE` 等宽小标签
- 中：4 个 HUD 状态条（跨平台红心/播放进度/同步完成度，每个= 图标+细进度条）
- 右：`SYNC 2/4` 等宽计数 + 收藏计数（❤ 图标 + 数字）

### 2. 中部主区（左右两栏）
- **左栏（约 45%）**：歌曲卡
  - 封面大图 400×400（圆角 16px，可先用渐变占位 + ♪ 符号），带霓虹青色描边光效
  - 下方：曲名（40px 粗体，如「走钢丝的人」）、艺术家（16px 次级，如「李泉 // 2001」）
  - 专辑名小标签（等宽 10px，如 `ALBUM: 走钢丝的人`）
  - 状态行：`HI-RES 24/96 FLAC LOSSLESS` 等宽标签
- **右栏（约 55%）**：歌词面板（玻璃卡）
  - 顶部：`LYRICS_DATA // 001` 等宽小标签
  - 中间 3 行歌词：前一行（白 30%）、当前行（白 100% + 霓虹青竖条指示器 ▶）、后一行（白 30%）
  - 底部：来源标注（`SYNCED FROM NETEASE` 等宽 9px）

### 3. 左下：DeepSeek AI 推荐区（ENCounter log）
- 标题条：`#092 · DEEP.SEEK · ENCOUNTER LOG`（等宽 10px，酸紫色）
- 3 张迷你卡（横排）：每张 = 小封面（32px 圆角方块，不同色相渐变）+ 歌名（12px）+ 艺术家
  （10px）+ `98% MATCH` 徽章（酸紫填充圆角）
- 底部：`AI 评估：92% MATCH` 等宽 9px

### 4. 右下：控制菜单（2×2 + 中央大播放键 + 右侧 2×2）
- 左 2×2：FIGHT(红)/BAG(黄)/PKMN(绿)/RUN(蓝)——等宽 10px 标签按钮，圆角 8px，描边式
- 中央：大播放键（72px 圆形，霓虹青填充 + 发光，白色 ▶/⏸ 图标）
- 右 2×2：⏮/⏭ 图标按钮 + 随机/循环（图标按钮，描边式）

### 5. 底部进度条（全宽）
- 当前时间（等宽 11px 左）+ 进度条（细 4px，霓虹青填充 + 圆形滑块，白 30% 轨道）+ 总时长（右）

### 6. 平台徽章 ×4（顶部条下方右侧，竖排或横排）
- QQ(黄 Q)/网易云(红 N)/Deezer(蓝 D)/Spotify(绿 S)——圆形徽章 28px，霓虹描边，当前平台
  高亮（填充 + 发光）

## 设计原则
1. 保持现有功能布局一个不少（这是产品功能清单，不是装饰）
2. 视觉语言 AETHER：深空黑底、霓虹青×电紫、玻璃面板、等宽 HUD 标签
3. 中文界面，HUD 标签可用英文科幻短词（TRACKING / SYNC / NEURAL FEED）
4. 所有元素用 auto-layout + 变量，方便后续调整
